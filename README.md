# АвтоПарк-Контроль

Информационная система учёта и управления эксплуатацией автотранспорта предприятия (УП.05, ПМ.05 «Проектирование и разработка информационных систем»).

## Назначение и основные функции

Система «АвтоПарк-Контроль» предназначена для автоматизации диспетчерского учёта автотранспортного предприятия (АТП):
- **Автопарк (ТС)** — регистрация транспортных средств, редактирование характеристик, смена статусов (`Свободен`, `В рейсе`, `На ТО`), поиск, фильтрация и удаление записей.
- **Водители** — ведение реестра водительского состава, учёт категорий ВУ, стажа, закреплённых автомобилей и оперативных статусов.
- **Путевые листы** — оформление путевых листов с автоматическим расчётом планового расхода ГСМ (норма 0,13 л/км) и закрытием рейсов.
- **ТО и ремонты** — журнал технического обслуживания и регламентных работ.
- **Аналитика и ГСМ** — сводные показатели коэффициента готовности парка, пробега и эксплуатационных расходов.
- **Безопасность и контроль доступа (RBAC)** — разграничение прав по ролям (`Диспетчер`, `Администратор`, `Наблюдатель`), защита от XSS/инъекций при вводе данных, проверка целостности (запрет удаления ТС «В рейсе» и повторного закрытия ПЛ), журнал событий безопасности.

## Структура проекта

- `index.html` — точка входа (App Shell с фиксированной боковой панелью, 5 разделами и модальными окнами)
- `css/fleet.css` — дизайн-система (хвойный `#1B4D3E`, обсидиан `#181A18`, алебастр `#F3F1EC`, терракота `#C2410C`, WCAG 2.1 AAA/AA)
- `js/data/fleetStore.js` — слой хранения данных (`LocalStorage API` + начальные эталонные данные)
- `js/modules/fleetSecurity.js` — модуль безопасности: ролевая модель (RBAC), санитизация ввода, защита от XSS и журнал аудита СБ
- `js/modules/fleetValidator.js` — клиентская валидация форм (ТС, водители, путевые листы) и проверка небезопасных конструкций
- `js/modules/fleetService.js` — бизнес-логика, проверка прав доступа, расчёт расхода ГСМ и аналитические KPI
- `js/ui/fleetRenderer.js` — рендеринг таблиц, карточек KPI, госномеров РФ и уведомлений (Toast)
- `js/app.js` — маршрутизация SPA, модальные окна, управление ролями, экспорт JSON и сброс данных
- `database/autopark_control.sql` — SQL-дамп базы данных для импорта в **phpMyAdmin** (MySQL / MariaDB)

## Инструкция по запуску

### Вариант 1. Локальный веб-сервер (рекомендуется)

1. Откройте терминал в корневой папке проекта `autopark-control`.
2. Запустите встроенный HTTP-сервер Python:
   ```bash
   python -m http.server 8080
   ```
3. Откройте в браузере адрес `http://localhost:8080/index.html`.

### Вариант 2. Прямое открытие файла

Откройте файл `index.html` двойным щелчком в современном браузере (Google Chrome, Microsoft Edge, Mozilla Firefox).

### Развёртывание базы данных (phpMyAdmin)

Файл `database/autopark_control.sql` содержит SQL-скрипт создания базы данных `autopark_control` (`utf8mb4_unicode_ci`) со связанными таблицами `vehicles`, `drivers`, `waybills` и `maintenance_records` и эталонными записями. Для развёртывания откройте phpMyAdmin → вкладка **Импорт** → выберите `database/autopark_control.sql`.

## Порядок работы с системой

1. По умолчанию активна роль **Диспетчер** (доступны просмотр, добавление/редактирование ТС, водителей, оформление и закрытие путевых листов, экспорт JSON; удаление записей и сброс БД ограничены).
2. Для переключения роли или просмотра журнала событий безопасности нажмите кнопку **«Права и СБ»** в нижней части боковой панели:
   - **Диспетчер** — оперативный учёт без удаления записей и сброса базы;
   - **Администратор** (PIN-код: `1234`) — полный доступ ко всем операциям;
   - **Наблюдатель** — режим «Только чтение» для аудита.
3. Для выгрузки резервной копии нажмите **«Экспорт JSON»** в верхней панели инструментов.
